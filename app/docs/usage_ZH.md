## 1. 使用前准备

运行客户端前确认：

- Robot已经安全放置，首次测试建议悬空，并准备独立的物理急停方式。
- 控制服务可通过 TCP `8081` 访问。
- 使用相机时，视频服务可通过 TCP `8080` 访问。
- 手机或电脑和 Robot位于同一网络，或者已经连接 Robot热点。
- 浏览器版本通过 HTTPS 打开时，机器人端同时支持 HTTPS/WSS，避免混合内容被拦截。

默认地址：

| 用途 | 地址 |
| --- | --- |
| 设置与控制 HTTP | `http://<D1-IP>:8081` |
| 状态与控制 WebSocket | `ws://<D1-IP>:8081/ws/robot` |
| SSH 隧道 | `ws://<D1-IP>:8081/ws/ssh` |
| MJPEG 视频 | `http://<D1-IP>:8080/stream?topic=/image_raw` |

## 2. 连接机器人

连接页有两种方式：

### 地址连接

1. 选择 **Address / 地址**。
2. 输入 IP、`host:port`、HTTP URL 或完整 WebSocket URL。
3. 没有显式填写端口时默认使用 `8081`。
4. 点击 **Connect To Robot / 连接机器人**。

### Robot热点

默认热点控制地址是 `192.168.50.1:8081`。

- **网页端**：浏览器不能替用户切换系统 Wi-Fi。先在系统 Wi-Fi 中手动连接 Robot热点，再回到网页点击连接。
- **Android App**：点击热点按钮会打开系统 Wi-Fi 列表。选择 Robot热点并返回 App 后，客户端检测默认地址；检测成功可直接进入 Map 页面，失败时可在连接页重新检测。
- 热点可能提示“无互联网”，应选择继续保持连接。

连接过程：

```text
GET /api/settings
  → WebSocket /ws/robot
  → 发送一次零速度
  → 进入 Map 页面
```

任一步骤失败都会停留在连接页并显示错误。

## 3. Map 页面总览

Map 页面由以下区域组成：

| 区域 | 内容 |
| --- | --- |
| 左上状态栏 | 平移速度、旋转速度、导航状态、诊断状态 |
| 左侧工具栏 | 图层、重定位、手柄输出、控制日志、相机、手动控制 |
| 右侧工具栏 | 设置、地图编辑、SSH、放大、缩小、跟随机器人 |
| 右上动作区 | 站起/趴下、进入/退出强化学习模式 |
| 左下摇杆 | 前后和横向移动 |
| 右下摇杆 | 左右旋转 |
| 右上图例 | Free、Occupied、Unknown 地图栅格含义 |

地图可显示机器人位姿、导航点、拓扑线、激光、点云、路径、轨迹、footprint 和代价地图。没有地图数据或地图元数据返回 `404` 时，客户端显示带有 `NAVBOT` 障碍字样的前端占位地图，并继续等待真实地图。

## 4. 每个按钮的功能

### 4.1 左上状态栏

| 图标/状态 | 功能 |
| --- | --- |
| 速度表 | 显示左摇杆实际下发的平面合成速度 `sqrt(vx² + vy²)`，单位 `m/s` |
| 旋转箭头 | 显示右摇杆实际下发的角速度，单位 `deg/s` |
| 导航箭头 | 显示当前导航状态，例如 `unknown`、`accepted`、`executing` |
| 诊断状态 | 正常时显示 Normal；有 WARN/ERROR 时显示数量；点击进入诊断详情 |

这里显示的是客户端实际准备下发的控制值，不是机器人通过里程计反馈的实测速度。

### 4.2 左侧工具栏

| 按钮 | 功能 | 操作说明 |
| --- | --- | --- |
| 图层 | 打开图层设置 | 启用/关闭地图栅格、局部代价地图、激光、点云、全局/局部路径、轨迹、拓扑和 footprint，并可调整部分颜色、阈值和点大小 |
| 重定位 | 设置机器人初始位姿 | 点击后在地图上拖动位置并调整方向；点击绿色勾确认发送，点击红色叉取消 |
| 手柄输出 | 显示实时输入面板 | 用于查看摇杆轴、按键和换算后的 `vx/vy/vw`；这是临时调试面板，不是持久日志 |
| 控制日志 | 打开控制日志页面 | 只在设置中启用 Control logs 后显示；默认不显示且不记录 |
| 相机 | 打开/关闭相机浮窗 | 相机浮窗内的全屏按钮可切换全屏显示 |
| 手柄/手动控制 | 显示/隐藏虚拟摇杆和动作按钮 | 进入手动控制后使用左右摇杆控制 Robot|

### 4.3 右侧工具栏

| 按钮 | 功能 | 操作说明 |
| --- | --- | --- |
| 设置 | 打开客户端设置 | 修改连接、速度、视频、话题、SSH、图层、日志和屏幕方向 |
| 地图编辑 | 进入地图编辑页面 | 可编辑点位、拓扑线和障碍；保存操作会写入机器人端 |
| SSH Hub | 展开/收起 SSH 工具 | 展开后显示“快捷指令”和“交互终端”两个按钮 |
| 闪电 | SSH 快捷指令 | 执行设置中配置的快捷命令 |
| 终端 | SSH 交互终端 | 打开交互式终端 |
| 放大 | 放大地图 | 物理手柄 `X` 也会触发放大 |
| 缩小 | 缩小地图 | 缩小当前地图 |
| 定位圆环 | 跟随机器人 | 绿色表示启用，地图持续以机器人为中心；再次点击恢复自由浏览 |

### 4.4 右上动作按钮

| 按钮 | 物理手柄 | 功能 |
| --- | --- | --- |
| Stand | `A` | 发送站起命令 |
| Lie Down | `B` | 发送趴下命令 |
| Enter RL / Exit RL | `方向键上 + R1` | 进入或退出强化学习控制模式 |

Stand/Lie Down 共用一个按钮区域，当前高亮表示客户端保存的最近模式状态。模式命令等待匹配 ACK，默认超时为 3 秒；ACK 表示命令已接受，不表示实体动作已经完成。

### 4.5 地图和导航点

| 操作 | 功能 |
| --- | --- |
| 拖动地图 | 平移地图 |
| 双指缩放/滚轮 | 缩放地图 |
| 点击导航点 | 打开点位详情 |
| Send Nav Goal | 将选中的导航点作为目标发送 |
| 蓝色停止按钮 | 仅在导航处于 accepted/executing 时出现，用于取消当前导航 |

## 5. 虚拟摇杆与速度显示

### 左摇杆

- 上/下：前进和后退，对应 `MaxVx`。
- 左/右：横向移动，对应 `MaxVy`。
- 斜向：同时产生 `vx` 和 `vy`。

### 右摇杆

- 左/右：旋转，对应 `MaxVw`。

换算公式：

```text
vx = MaxVx × 左摇杆 Y
vy = MaxVy × -左摇杆 X
vw = MaxVw × -右摇杆 X
顶部平移速度 = sqrt(vx² + vy²)
```

因此 `MaxVx` 和 `MaxVy` 可以不同。例如 `MaxVx=0.9`、`MaxVy=0.5` 时，满幅前进显示约 `0.90 m/s`，满幅横移显示约 `0.50 m/s`。

有效手动速度以 `20ms` 周期发送，即 `50Hz`。松开摇杆会回到零速度。

## 6. 物理手柄映射

| 输入 | 功能 |
| --- | --- |
| 左摇杆 | 前后/横向移动 |
| 右摇杆 | 左右旋转 |
| `A` | 站起 |
| `B` | 趴下 |
| `X` | 地图放大 |
| `Y` | 当前未绑定 |
| `方向键上 + R1` | 进入/退出强化学习模式 |
| `L1`、`L2`、`R2`、单独 `R1` | 当前无动作 |

方向键上和 `R1` 的组合按键间隔必须不超过 `320ms`。

## 7. 导航、重定位与地图编辑

### 导航

点击地图导航点，检查点位信息后点击 **Send Nav Goal**。导航执行期间出现停止按钮，可发送取消导航。

### 重定位

1. 点击左侧重定位按钮。
2. 在地图上移动初始位置和朝向。
3. 点击绿色勾发送，或点击红色叉取消。

### 地图编辑页面按钮

顶部按钮：

| 按钮 | 功能 |
| --- | --- |
| Undo | 撤销最近一次点位、拓扑或障碍编辑；桌面端也可按 `Ctrl+Z` |
| Save | 保存到当前地图 |
| Save As | 输入新名称并另存地图 |
| Map Management | 查看地图列表、切换、编辑或删除非当前地图 |
| Add Current Position | 仅在 Point 工具启用时显示，以机器人当前位置添加导航点 |
| Close | 退出地图编辑 |

右侧编辑工具：

| 工具 | 功能 |
| --- | --- |
| Move | 浏览地图、选择并拖动导航点 |
| Point | 点击地图添加导航点 |
| Route | 依次点击起点和终点创建拓扑线 |
| Brush | 绘制障碍栅格 |
| Eraser | 清除障碍栅格 |
| Brush size | Brush/Eraser 启用时调整 `0.05–1.0m` 的笔刷大小 |

点击已有点位可修改名称、坐标、角度和类型，或删除点位；点击已有拓扑线可查看控制器或删除拓扑线。删除地图和覆盖保存前应确认目标名称。

## 8. 设置、图层、相机、SSH 与日志

### 关键速度配置

| 配置 | 含义 |
| --- | --- |
| `MaxVx` | 前后最大速度，单位 `m/s` |
| `MaxVy` | 横向最大速度，单位 `m/s` |
| `MaxVw` | 最大角速度，单位 `rad/s` |

### 相机

默认视频地址：

```text
http://<D1-IP>:8080/stream?topic=/image_raw
```

可在设置中修改 `imagePort`、`imageTopic`、`imageWidth` 和 `imageHeight`。

### SSH

SSH 快捷指令和终端通过 `/ws/ssh` 使用机器人端隧道。首次使用前需填写 SSH 端口、用户名和密码。不要在不可信的 HTTP/WS 网络中传输凭据。

### 控制日志

控制日志默认关闭。关闭时：

- Map 页面不显示控制日志按钮。
- 不向内存环形缓冲区写入控制日志。
- 减少高频控制过程的额外性能开销。

排查手柄时可临时启用，检查设备事件、原始轴、`vx/vy/vw`、发送频率和 WebSocket 状态，完成后建议关闭。

## 9. 安全与失联行为

- 当前 UI **没有独立急停按钮**，不要把 Stand、Lie Down 或取消导航当作物理急停。
- 首次实体测试前应悬空机器人，并准备机器人侧或硬件侧急停方法。
- 连接断开、应用暂停、手柄设备变化或停止手动控制时，客户端会清除旧控制状态。
- 超过 10 秒没有收到机器人消息时，客户端认为连接失活并尝试重连。
- 客户端写入 WebSocket 或收到模式 ACK，不等于机器人已经完成动作；必须观察实体状态和诊断反馈。
- 开放热点没有网络认证时，附近设备可能访问控制接口，只能在受控环境使用。

## 10. 常见问题

### 读取 settings 失败

确认 IP、TCP `8081` 和 `GET /api/settings` 可访问。设置读取失败时客户端不会继续建立主 WebSocket。

### 网页无法自动连接 Robot热点

这是浏览器安全限制。用户必须在操作系统 Wi-Fi 页面中手动连接热点，再返回网页点击连接。

### WebSocket 反复重连

确认机器人持续发送状态或心跳。超过 10 秒没有任何消息会触发失活判断。

### 左右移动时速度不正确

确认 `MaxVy` 配置。顶部第一个速度值是 `sqrt(vx² + vy²)`，横向移动不会使用 `MaxVx`。

### 物理摇杆没有响应

临时启用 Control logs 或打开手柄输出面板，检查设备 ID、轴事件以及计算后的速度。

### 相机无法显示

直接访问 MJPEG URL，检查端口、话题、CORS 以及 HTTPS 页面加载 HTTP 视频时的混合内容限制。

### 地图返回 404

客户端会显示前端占位地图并继续重试。占位地图仅用于保持界面可用，不能用于真实导航。

### 机器人没有移动

确认连接正常、手动控制已打开、速度输出持续更新，并确认机器人侧没有急停、模式或安全保护。前端只能确认命令已写入连接，无法单独确认执行结果。
